# Keyboard and mouse

The shortcuts and gestures of NebulaStudio, as Windows has them.

## Menus

| Shortcut | Does |
| --- | --- |
| Ctrl+N | **File** > **New** |
| Ctrl+O | **File** > **Open...** |
| Ctrl+S | **File** > **Save** |
| Ctrl+Shift+S | **File** > **Save As...** |
| Ctrl+Alt+S | **File** > **Save Galaxy**, the galaxy shown |
| Ctrl+Z | **Edit** > **Undo** |
| Ctrl+Shift+Z, Ctrl+Y | **Edit** > **Redo** |
| Ctrl+X | **Edit** > **Cut** the instances selected |
| Ctrl+C | **Edit** > **Copy** the instances selected |
| Ctrl+V | **Edit** > **Paste** |
| Ctrl+D | **Edit** > **Duplicate** the instances selected |
| Ctrl+Shift+F | **View** > **Find Instances** |
| Ctrl++ | **View** > **Zoom In** |
| Ctrl+- | **View** > **Zoom Out** |
| Ctrl+0 | **View** > **Actual Size** |
| F5 | **Run** > **Start** |
| Shift+F5 | **Run** > **Stop** |
| Ctrl+F | Search the **Components** tab |

While a name or a field is typed, Ctrl+Z, Ctrl+X, Ctrl+C and Ctrl+V act on what is typed there.

## The edition zone

| Gesture | Does |
| --- | --- |
| Drag from a list, drop in the zone | Places a component, or a galaxy |
| Click, drag a rectangle | Selects |
| Drag an instance | Moves it, and those selected with it |
| Delete | Removes the instances, links, settings files and stargates selected |
| Double-click the names of an instance | Renames it; Enter keeps the name, Escape gives it up |
| Double-click a galaxy or a stargate, below its name | Opens the galaxy, or the dialog of the stargate |
| Double-click a settings file | Opens its dialog |
| Drag from a dot to another one | Binds the two interfaces |
| Escape, while a link is drawn | Gives it up |
| Right-click a dot | Its menu: **Bind to**, **Expose...** |
| Shift+right-click a dot | Its edge and its row: **Dot on the left edge**, **Dot on the right edge**, **Swap with** |
| Double-click a link | Adds an anchor there |
| Drag an anchor | Moves it |
| Double-click an anchor | Removes it |
| Shift+drag from a link or an anchor to a dot | Binds that interface through a junction on the link |
| Double-click a junction | Has each link through it go its own way again |
| Drag a zone by its title | Moves it, with what is in it |
| Drag the edge or the corner of a zone | Resizes it |
| + and - | Zoom in and out around the middle |
| Ctrl+mouse wheel | Zoom in and out around the cursor |
| Middle button held, drag | Moves the view |

## The lists and the properties

| Gesture | Does |
| --- | --- |
| Double-click a galaxy in the **Galaxies** tab | Opens it in place of the application |
| Double-click a row of the problems, or Enter on it | Shows its instance |
| Click a value | Edits it |
| Double-click a color, or F2, or Space | Opens the color dialog |
| Enter, in the field that finds instances | Shows the next instance found |
